## 要做什麼 / What to do

做一個 **BMI 計算器網頁應用**，介面文字全部用**繁體中文（台灣用語）**。

## 格式 / Format

- **單一 HTML 檔**（HTML + CSS + JavaScript 全部內嵌），不另外拆檔、不引用外部 CDN 或網路資源。
- 檔名：`bmi-calculator.html`
- 存放位置：`workspace/outbox/`（另存新檔，不要覆蓋任何既有檔案）
- 需要填寫的欄位：
  - 身高（公分 cm）
  - 體重（公斤 kg）
- 計算：`BMI = 體重(kg) / 身高(m)²`
- 按鈕：「計算」與「清除」
- 顯示結果：
  - BMI 數值，**四捨五入到小數點後一位**
  - 所屬分類（依台灣衛福部標準）：
    - 過輕：BMI < 18.5
    - 正常：18.5 ≤ BMI < 24
    - 過重：24 ≤ BMI < 27
    - 肥胖：BMI ≥ 27
  - 分類要用顏色或標籤清楚區分
- 輸入檢查：非數字、空值、身高或體重 ≤ 0 時，顯示錯誤訊息，不要輸出結果。
- 版面：手機與桌機都可正常使用（基本 RWD 即可）。

## 怎樣算做完 / What "done" looks like

1. `workspace/outbox/bmi-calculator.html` 存在。
2. 用瀏覽器打開即可運作，無錯誤訊息、無外部資源依賴。
3. 輸入身高 170、體重 65 → 顯示 BMI 22.5、分類「正常」。
4. 輸入非法值（例如身高 -1）→ 顯示錯誤訊息而非結果。
5. 介面文字全為繁體中文。
